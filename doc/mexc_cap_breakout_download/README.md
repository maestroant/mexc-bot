# MEXC — торговля после снятия ценового потолка

Состав комплекта:

- `MEXC_CAP_BREAKOUT_TZ.docx` — полное ТЗ с четырьмя схемами (Word).
- `MEXC_CAP_BREAKOUT_TZ.md` — редактируемая текстовая версия ТЗ.
- `MEXC_CAP_BREAKOUT_MINDMAP.png/.svg` — общая структурированная карта действий.
- `MEXC_FAST_BREAKOUT.png/.svg` — подробные действия алгоритма FAST.
- `MEXC_CONFIRMED_BREAKOUT.png/.svg` — подробные действия алгоритма CONFIRMED.
- `MEXC_POSITION_EXIT_PROTECTION.png/.svg` — TP1/TP2, проскальзывание, общий PnL и аварийные выходы.
- `MEXC_CAP_BREAKOUT_SCHEMES.drawio` — 4 редактируемые страницы схем в diagrams.net.
- `MEXC_CAP_BREAKOUT_CONFIG.yaml` — единый стартовый конфиг для REPLAY/PAPER.

Все проценты и интервалы — настройки для тестирования, не подтверждённая доходность. В конфиге LIVE по умолчанию отключён.
