# Предрегистрация вариантов для новых листингов

**PREREG_ID:** `PR-2026-11-06`. Действует для листингов, открывшихся после выкладки 06.11.2026. Константы — в
`tools/core/cap_breakout.py` (`PREREG_ID`, `MAIN_EARLY_PAPER`, `MAIN_EARLY_EXITS`); PAPER пишет `prereg` в START и
SUMMARY своего лога, `tools/paper_report.py` считает этот набор отдельно.

Правило (клиент 05.11): варианты фиксируются до появления листингов, по которым их сравнивают. Изменить набор можно
только новым PREREG_ID; листинги, прошедшие при старом наборе, к новому не добавляются. Оптимум по прошлым листингам
(в том числе по EMYA) не выбирается.

## Что сравнивается

**BASELINE (ТЗ v2.1)** — без изменений, контроль: окно 8 с, прогрев 500 мс, фильтры v2.1, выход MAIN_V21, 10 USDT.

**MAIN_EARLY** — только REPLAY и PAPER, только листинги без потолка. 18 комбинаций входа × 5 выходов × 2 плана:

| Параметр | Значения |
|---|---|
| Окно входа от T0 | 2 с, 5 с |
| Рост от первого действительного bestAsk | ≤ 40 % |
| Импульс | нет; 250 мс базовый (midPrice вырос, bestBid не упал); 250 мс строгий (bestBid вырос ≥ шага цены) |
| Глубина bids | 0,7 % ≥ 5× плана, 1,5 % ≥ 10× плана |
| Возраст стакана | ≤ 100 / 250 / 500 мс |
| План | 2 USDT, 10 USDT |
| Постоянные условия | спред ≤ 3 %; весь плановый BUY исполним по asks до bestAsk +1 %; exitVWAP-проскальзывание ≤ 1,5 %; без требования updatesPerSec; несинхронизированный или повреждённый стакан — вход запрещён |

Выходы:

| Выход | Правило |
|---|---|
| MAIN_V21 | стандартный выход ТЗ v2.1 (TP +2 % / +4 %, временные стопы, удержание 15 с) |
| MAIN_TP_TRAIL | TP1 +2 % на 50 %, остаток — trailing 5 % от максимума исполнимого bid-VWAP, защита общего netPnL +0,3 %, maxHold 30 с, временные стопы действуют |
| MAIN_TP_TRAIL_NT | то же; после **полного** исполнения TP1 TIME_STOP_NEGATIVE / NO_EDGE / NO_MOMENTUM для остатка выключены (при частичном — действуют) |
| MAIN_TP_FULL | один TP +2 % на всю позицию, стопы MAIN_V21, maxHold 30 с |
| MAIN_TRAIL_ALL | без TP: trailing 5 % от максимума bid-VWAP всей позиции включается, когда bid-VWAP достиг цены входа +2 %; дальше — как MAIN_TP_TRAIL_NT |

Во всех выходах с защитой +0,3 % она включается, только когда расчётный общий netPnL (комиссии и резерв проскальзывания
учтены один раз) достиг +0,3 %; уровень не гарантирует прибыльного исполнения. Если при делении позиции любая часть не
проходит minNotional с запасом 10 % или qtyStep — один TP на весь фактический объём; заведомо непродаваемый остаток не
создаётся.

**CAP BREAKOUT** — отдельно, без изменений (FAST, CONFIRMED, EARLY).

## Как оцениваются

Не только по итогу. По каждой комбинации:

- итог, USDT;
- итог без лучшего листинга;
- худшая сделка, USDT и %;
- исполненный объём BUY, USDT;
- непроданный остаток;
- качество данных: листинги с разрывом версий стакана или восстановленными интервалами показываются отдельно и в выводы
  не входят.

Решение о LIVE по этим данным не принимается: ничего нового в LIVE не переводится.
